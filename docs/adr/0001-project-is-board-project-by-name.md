# A Roost project is the Board project of the same name

Roost projects (named groups of folders across hosts) and VinhLam Board projects (`<project>/build` channels) share one word, so they are one concept: a Roost project whose name matches a Board project (case-insensitive) is that Board project and shows its open work, while any other Roost project is just a folder group. We chose a name match over a stored link or a separate word ("Workspace") so there is one meaning of "project" and no mapping to keep in sync; renaming a project to a Board name is how you link it.
